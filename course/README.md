# Claude Code로 만드는 AI 에이전트 팀
## — 부동산 멀티레이어 맵서비스 실전 구축

> 패스트캠퍼스 실습형 강의 · 수강생 따라하기 교안

이 강의는 **AI 에이전트 여러 대를 팀으로 묶어** 하나의 실전 서비스를 만드는 과정을 처음부터 끝까지 따라합니다. 최종 산출물은 **서울+수도권 경매물건 9,759건과 정비구역 2,585건을 한 지도에 얹은 인터랙티브 부동산 맵**입니다.

단순히 "지도 만들기"가 목표가 아닙니다. **재사용 가능한 에이전트 팀(하네스)을 설계하는 사고방식**을 배우는 것이 핵심입니다. 이 원리는 부동산 지도뿐 아니라 어떤 도메인에도 그대로 적용됩니다.

---

## 이 강의를 마치면 할 수 있는 것

- **하네스(Harness)** 개념을 이해하고, 도메인을 에이전트로 분해할 수 있다
- `.claude/agents/`와 `.claude/skills/`로 에이전트 팀과 스킬을 정의할 수 있다
- 에이전트들이 **병렬 수집 → 통합 → 검증**하도록 오케스트레이션할 수 있다
- **표준 데이터 계약(GeoJSON)** 으로 레이어를 무한 확장 가능하게 설계할 수 있다
- 실제 데이터로 지도를 산출하고, **버그를 QA로 잡고**, 반복 개선할 수 있다
- 데이터가 없을 때 **정직하게 처리**하는 엔지니어링 태도를 익힌다

| Claude Code | 설치 및 로그인 완료 ([claude.com/claude-code](https://claude.com/claude-code)) |

> 💡 이 강의의 핵심은 "코드를 직접 다 짜는 것"이 아니라 **에이전트에게 올바르게 일을 시키는 법**입니다. 코딩 경험이 적어도 따라올 수 있게 구성했습니다.

## 강의 진행 방식

이 강의는 **수강생 관점**으로 씌어 있습니다. 실제 데이터 수집·좌표 변환·렌더링 코드는 **에이전트가 알아서 처리**하므로, 여러분이 직접 짤 필요가 없습니다. 그래서 각 파트는 이렇게 진행됩니다:

> **⌨️ 무엇을 입력하는가 → 🤖 에이전트가 하는 일(요약) → 👀 보게 되는 결과 → 🧠 여러분이 내리는 판단**

각 파트 구조:
1. **🎯 학습목표** — 이 파트에서 할 수 있게 되는 것
2. **📖 핵심개념** — 원리 설명 (왜 이렇게 하는가)
3. **⌨️ 따라하기** — 실제 입력할 프롬프트와 기대 결과
4. **✅ 체크포인트** — 제대로 됐는지 확인하는 법
5. **⚠️ 흔한 실수** — 우리가 실제로 겪은 함정과 해결

> 🔍 **심화 상자**: 에이전트가 내부적으로 처리하는 실제 코드(파이썬·JS·git 등)는 접이식 `심화` 상자에 넣어 뒀습니다. **궁금한 수강생만 펼쳐 보면 되고, 안 봐도 실습에는 지장 없습니다.**
