
- 거리·면적: **마우스를 누른 채 드래그**하면 선/영역이 그려지고(확대 레벨에 비례한 간격으로 점 자동 추가), **더블클릭**으로 마무리. 클릭으로 점을 하나씩 찍는 것도 그대로 가능. 그리는 동안 지도 이동·더블클릭 확대는 잠기고 끝나면 풀린다.
- 실측: 드래그 21점 → 총 거리 783 m, 영역 드래그 → 20,000㎡(6,050평).

**🧠 배우는 것 (함정)** — 카카오 SDK는 버튼을 누른 채 움직이면 `mousemove` 이벤트를 주지 않는다(드래그로 처리). 그래서 지도 컨테이너의 **DOM mousemove**를 받아 `map.getProjection().coordsFromContainerPoint()`로 픽셀→좌표 변환해야 프리핸드 그리기가 된다. 처음엔 SDK 이벤트만 써서 드래그 중 점이 1개만 찍혔다.

## 12. 정비사업구역 클릭 → 구역 정보

**⌨️ 프롬프트**
```
카카오맵레이어에서 정비사업구역을 누르면 어떤구역인지 보여줘.
```
**🤖 결과**
- 원인: 구역 폴리곤 클릭 팝업은 있었지만, 폴리곤 `click` 직후 지도 `click`도 발생해 `closeKakaoPopup()`이 바로 닫아 버렸다. 폴리곤 클릭 시 플래그를 세우고 지도 클릭 한 번을 무시하도록 수정.
- 추가: 폴리곤에 **마우스를 올리면** 구역명·사업유형·추진단계 툴팁, 테두리 강조. 클릭 팝업에 평 환산 면적·구역ID와 **구역 내 진행 중인 경매물건 목록**(클릭 시 해당 물건 팝업으로 이동)을 넣었다.
- 검증(실제 마우스): 신반포2차 → 정비사업 · 신속통합기획 · 기획완료 · 서초구 · 116,071㎡(35,111평) · 구역 내 경매 1건(2024타경111351, 최저 23억 2,000만원) → 클릭 시 물건 팝업 전환.

**🧠 배우는 것** — 카카오맵에서 도형 위를 클릭하면 도형 `click`과 지도 `click`이 **둘 다** 발생한다. 지도 클릭에 "팝업 닫기"를 걸었다면 도형 클릭이 먼저 처리된 뒤 한 번은 건너뛰게 해야 한다. 팝업이 "떴다가 사라지는" 증상이면 이것이다.
