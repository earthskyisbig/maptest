STEP 1 · 2 — 재료 준비

서울 아파트 경매 지도, 재료는 두 개

1정비사업 구역 (면 · SHP 파일)

  • 서울열린데이터광장에서 "서울플랜+ 도시계획사업" 공간정보 SHP 최신본 다운로드
  • 또는 브이월드 → 주제도 검색창에 '정비' → 도시및주거환경정비 / 정비구역 다운로드
  • 받은 zip 그대로 두면 됨. 압축 해제·좌표 변환은 클로드가 함

2경매물건 (점 · DuckDB)

▶서울(수도권) 아파트 최근 경매물건을 크롤링해서 정규화하고 DuckDB에 저장해줘
  • 에이전트가 법원경매 사이트에서 전량 수집 → 물건번호·유찰·감정가·최저가·면적·매각기일·특이사항 정리
  • 결과: data/estate.duckdb 한 파일. 나중에 같은 문장으로 다시 시키면 갱신
준비물 하나 더 (빠뜨리면 지도가 안 뜸) 카카오 developers에서 앱 만들기 → JavaScript 키 복사 → 플랫폼 > Web 사이트 도메인에 http://localhost:8000 등록. 브이월드 배경지도도 쓰려면 브이월드 인증키까지 (선택).
STEP 3 · 4 · 5 — 클로드에게 시키기

하네스 → 요구사항 → 확인·갱신

③ 하네스 에이전트

에이전트 팀을 만들고 재료를 준다

▶/harness 이 워크스페이스는 부동산 맵서비스다. 경매물건·정비구역을 한 지도 위 레이어로 보여준다
▶서울플랜 구역 파일과 DuckDB 경매물건으로 카카오맵 위에 레이어를 구성해줘
④ 화면 요구사항 (4가지로 말하기)
  • 색상 — 마커 파랑, 관심물건은 금색, 구역은 사업유형별 색
  • 정보 범위 — 물건번호·유찰·감정가·최저가·면적·매각기일·특이사항. 용도·전화번호는 빼기
  • 필터 — 구 · 유찰 · 면적 · 감정가 · 최저가 · 매각기일
  • 도구 — 스카이뷰·로드뷰·클러스터, 주소검색·장소저장·주변·거리/면적/반경 재기
▶마커는 파란색, 팝업은 절반 크기로 줄이고 스크롤, 관심물건은 저장하면 마커 색이 바뀌게…
⑤ 확인 · 갱신 (추가)

열어 보고, 하나씩 고치고, 주기적으로 갱신

  • 브라우저에서 열고 🔑에 카카오 키 입력 → 마커 클릭·구역 클릭·필터 동작 확인
  • 안 맞으면 한 번에 하나씩 "○○ 고쳐줘" (예: 구역 누르면 정보 보여줘)
  • 경매는 "다시 수집해서 지도 갱신해줘" 한 문장. 구역은 새 SHP 받아 교체
요령 요구사항을 처음부터 완벽하게 쓰려 하지 말고 결과를 보며 한 번에 하나씩 고친다.
