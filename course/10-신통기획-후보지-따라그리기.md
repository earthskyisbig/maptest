# 10. 서울시 SHP보다 먼저 — 신속통합기획 후보지를 따라 그려 지도에 올리기

> 2026-09-10 실습. 재개발닷컴·아실에는 있는데 우리 지도에는 없는 "신통기획 후보지(2026년 선정)"를 채운다.

## 왜 우리 지도에는 없었나

| | 서울플랜+ SHP (우리 지도) | 재개발닷컴·아실 |
|---|---|---|
| 출처 | 서울 열린데이터광장 `도시계획사업 현황(서울플랜+) 공간정보` (UQ120) | 서울시 보도자료·정보몽땅 목록을 사람이 읽어 그림 |
| 갱신 | **반기** (최종 2026-02-11, 데이터 기준일 2025-12-31~2026-01-31) | 선정위원회 발표 직후 (며칠) |
| 도형 | 공식 폴리곤 | 대표지번 점 또는 필지 위에 손으로 그린 폴리곤 |
| 신뢰 | 법적 효력 없음(참고), 그러나 서울시 원본 | 비공식 수기, 지정 고시 후 교체 |

서울시 공식 채널인 [정비사업 정보몽땅 → 신속통합기획 → 재개발 공모 선정구역](https://cleanup.seoul.go.kr/cleanup/view/publicIntgrPlanArea.do)에는 2026년 수시선정 **26곳**이 이미 올라와 있지만, **대표지번·구역면적·용도지역 표 + 위치도 이미지**만 있고 SHP·엑셀·API가 없다. 그래서 "표를 읽고, 위치도를 보고, 필지를 골라 그리는" 반자동 작업이 필요하다.

## 무엇을 만들었나

```
정보몽땅 페이지 ──fetch_sintong_sites.py──▶ _workspace/sintong_sites.json (145곳 목록 + 2026년 26곳 위치도 이미지)
                                                    │
                                   build_zone_editor.py ─▶ sintong_zone_editor.html  (구역 그리기 도구)
                                                    │  브라우저에서 필지 클릭 → GeoJSON 내보내기
                                   merge_sintong_edits.py ─▶ _workspace/layer_zone_sintong.geojson
                                                    │
                                   build_auction_map.py ─▶ seoul_auction_map.html  (범례: 신속통합기획 후보지(정보몽땅))
```

- **구역 그리기 도구** `sintong_zone_editor.html`
  - 왼쪽: 후보지 26곳 목록(구역면적·선정 시기) → 클릭하면 대표지번으로 지도 이동 + 위치도 이미지 표시
  - 오른쪽 지도(카카오): **필지 클릭 모드**는 VWorld 연속지적도(`LP_PA_CBND_BUBUN`)를 화면 범위로 불러와 필지를 클릭해 담는다. VWorld 키가 없으면 **직접 그리기**(경계 클릭, 더블클릭 마감)
  - 면적 게이지: 담은 필지 면적 합 ÷ 정보몽땅 구역면적. 85~115%면 ✔ (큰 도로·공원은 구역에서 빠지는 경우가 많다)
  - 파란 외곽선: 서울플랜+에 이미 있는 신통구역 225개 (중복 그리기 방지)
  - 작업 내용은 브라우저 localStorage에 자동 저장. **⬇ GeoJSON 내보내기**로 파일화, **⬆ 불러오기**로 다른 PC 작업 합치기
- **자리표시**: 아직 안 그린 후보지는 대표지번 위치에 구역면적을 원으로 환산해 연한 빨강으로 표시(범례 "대표위치(면적 환산, 미작성)"). 그리면 진한 빨강 폴리곤으로 바뀐다.

## 따라 하기

```
python scripts/fetch_sintong_sites.py          # 정보몽땅에서 목록·위치도 수집 (--year 25 로 다른 연도)
python scripts/build_zone_editor.py            # 도구 페이지 생성
지도열기.bat  또는  python -m http.server 8000
```
1. `http://localhost:8000/sintong_zone_editor.html` 열기 → 🔑 에 카카오 JavaScript 키(경매 지도와 공유), VWorld 인증키 입력
2. 왼쪽 목록에서 후보지 클릭 → 위치도(빨간 선) 보며 지도에서 같은 필지를 클릭. 잘못 담으면 다시 클릭해 해제
3. 게이지가 100% 근처면 다음 후보지로. 26곳 × 10~20분
4. **⬇ GeoJSON 내보내기** → 다운로드 폴더에 `sintong_2026_edits.geojson`
```
python scripts/merge_sintong_edits.py          # 다운로드 폴더에서 자동으로 찾아 레이어로 변환
python scripts/build_auction_map.py            # 경매 지도 재생성 → 범례 "신속통합기획 후보지(정보몽땅)"
```

## 기술 메모 (수강생 질문 대비)

- **VWorld 데이터 API를 브라우저에서 직접**: `https://api.vworld.kr/req/data?service=data&request=GetFeature&data=LP_PA_CBND_BUBUN&geomFilter=BOX(...)&crs=EPSG:4326&format=json&callback=…` — JSONP라 프록시 없이 동작. 한 번에 1,000필지, 페이지 최대 6장. 축척 50m 이하(카카오 level ≤ 3)에서만 조회한다.
- **대표지번이 실제 필지가 아닐 때**: "구의동 46", "신월1동 229"는 카카오 주소검색이 실패한다. 후보 주소를 순서대로 시도한다 — 원문 → 행정동 숫자 제거(신월1동→신월동) → `산` 번지 → 부번 제거 → `-1` → 키워드 검색 → 동 중심. 26곳 모두 위치를 찾았다.
- **면적 계산**: 카카오 `Polygon.getArea()`(㎡). 필지 합 vs 정보몽땅 면적으로 빠진 필지를 잡아낸다.
- **union**: 내보낸 필지 묶음(MultiPolygon)을 `shapely.unary_union` + 0.5mm 버퍼로 실틈을 메워 한 폴리곤으로. 원본 필지 PNU 목록은 속성에 남긴다.
- **한계**: 위치도는 축척 없는 그림이라 경계 필지 1~2줄은 사람 판단이다. 정식 정비구역 지정 고시 후 서울플랜+ 반기 갱신본(UQ120)으로 교체하고, 이 레이어에서 해당 후보지를 지운다.
